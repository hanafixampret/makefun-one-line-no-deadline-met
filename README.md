A single-line joke that excuses a missed deadline.

> My calendar and I agreed on Friday; my calendar just never told me which Friday.

`main.ts` writes the line to `/output/entry.txt` (one line, 1–200 characters).

Run it with Node 22+:

```sh
node main.ts
```
